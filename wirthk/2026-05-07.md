
#汉字

阴码 逐行式 顺向 const unsigned char font_hz24[][72] = { ... };
`24`：每个汉字 = 24 行像素 × 24 列像素
`72`：一个汉字占用 72 字节
每 3 个字节 = 1 行像素（24 列）

核心：阴码、逐行式、顺向（必须懂）

 ① 逐行式
从上到下，一行一行存储
第 1 行 → 第 2 行 → ... → 第 24 行
每行 3 字节（24 位）

 ② 顺向
字节高位在前，低位在后
一个字节 `0x80` = 二进制 `1000 0000`
最左边的是第 1 位，最右边是第 8 位

 ③ 阴码（最重要！）
1 = 不亮 / 背景
0 = 亮 / 汉字笔画
