#GAP协议
GAP，全称 Generic Access Profile，负责管理 设备的连接和广播  并定义了设备在蓝牙通信中的角色。-负责连接

#GATT协议
GATT，全称 Generic Attribute Profile，在设备 建立连接后 生效 它定义了 数据交换 的框架和格式 GATT 基于一种客户端‑服务器（Client‑Server）架构。-负责通信

#UUID
蓝牙 SIG 标准基础 Primary Service（主服务），所有 BLE 外设强制自带
0x1800 Generic Access（GAP，通用访问服务）
0x1801 Generic Attribute（GATT，通用属性服务）
