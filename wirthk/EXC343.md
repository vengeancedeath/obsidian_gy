不是MIPI DSI信号，是LVDS信号
LVDS（Low Voltage Differential Signaling，低压差分信号）

#基本信息
ECX34 LVDS 架构：2 组时钟差分 + 最多 10 组数据差分（IF0+IF1），灵活配置 5L×1/5L×2/4L×2 三种输入模式

#SPI写入时序
支持普通传输 / 突发传输两种模式，强制最低位 (LSB) 优先传输
突发模式：传输多字节
普通模式：单字节

![[Pasted image 20260610133811.png]]

简化代码如下：

    uint8_t temp[2] = {0};
    volatile uint8_t aa = 0;
    HAL_StatusTypeDef res;
    temp[0] = addr;
    temp[1] = value;
    HAL_GPIO_WritePin(GPIOA, GPIO_PIN_4, GPIO_PIN_RESET);
    res = HAL_SPI_Transmit(&hspi1, temp, 2, 1000);
    if (res == HAL_OK)
        aa = 1;
    // printf("WRITE OK!\n");
    // printf("Reg 0x%02X write 0x%02X OK! \n", addr, value);
    else
        aa = 0;
    // printf("WRITE FAIL!\n");
    // printf("Reg 0x%02X write FAIL! \n", addr);
    HAL_GPIO_WritePin(GPIOA, GPIO_PIN_4, GPIO_PIN_SET);
    return res;
    
NOTE:
- 数据捕获从XCS 信号下降沿开始
- 当 XCS 处于低电平时，数据应在第 16 个 XSCK 上升沿被捕获
- 前 8 位数据被识别为寄存器地址，随后的 8 位数据被识别为写入值
- 当 XCS 处于低电平时，如果 XSCK 脉冲数少于 15 个，则数据无法被捕获，视为无效
- 当 XCS 处于低电平时，若切换到突发传输模式，地址 A 的数据捕获必须在第 16 个 XSCK 上升沿完成。第 16 个 XSCK 脉冲之后，第 17-24 位数据对应地址 A+1，第 25-32 位数据对应地址 A+2，以此类推，地址自动递增
- 突发传输必须传输8×N 位数据（N 为≥2 的整数），若 XSCK 脉冲数不是 8 的整数倍，则超出部分数据无效

#SPI读取时序
支持普通传输和突发传输两种模式，强制最低位 (LSB) 优先传输

-打开读功能寄存器0x80

-读取0x81寄存器的返回的值
-关闭读功能寄存器0x80

简化代码如下：

    uint8_t temp[2] = {0};
    HAL_StatusTypeDef res;
    
    temp[0] = 0x80;
    temp[1] = 0x01;
    HAL_GPIO_WritePin(GPIOA, GPIO_PIN_4, GPIO_PIN_RESET);
    res = HAL_SPI_Transmit(&hspi1, temp, 2, 1000);
    // if (res == HAL_OK)
    //     printf("WRITE 0x81H OK!(IN READ MODE)\n");
    // else
    //     printf("WRITE 0x81H FAIL!(IN READ MODE)\n");
    HAL_GPIO_WritePin(GPIOA, GPIO_PIN_4, GPIO_PIN_SET);
    
    temp[0] = 0x81;
    temp[1] = addr;
    HAL_GPIO_WritePin(GPIOA, GPIO_PIN_4, GPIO_PIN_RESET);
    res = HAL_SPI_Transmit(&hspi1, temp, 2, 1000);
    // if (res == HAL_OK)
    //     printf("WRITE 0x81H OK!(IN READ MODE)\n");
    // else
    //     printf("WRITE 0x81H FAIL!(IN READ MODE)\n");
    HAL_GPIO_WritePin(GPIOA, GPIO_PIN_4, GPIO_PIN_SET);
    
    temp[0] = 0x81;
    temp[1] = 0x00;
    uint8_t readBuf[2] = {0};
    HAL_GPIO_WritePin(GPIOA, GPIO_PIN_4, GPIO_PIN_RESET);
    res = HAL_SPI_TransmitReceive(&hspi1, temp, readBuf, 2, 1000);
    // if (res == HAL_OK)
    //     printf("READ OK!\n");
    // else
    //     printf("READ FAIL!\n");
    HAL_GPIO_WritePin(GPIOA, GPIO_PIN_4, GPIO_PIN_SET);
    
    temp[0] = 0x80;
    temp[1] = 0x00;
    HAL_GPIO_WritePin(GPIOA, GPIO_PIN_4, GPIO_PIN_RESET);
    res = HAL_SPI_Transmit(&hspi1, temp, 2, 1000);
    // if (res == HAL_OK)
    //     printf("WRITE 0x81H OK!(IN READ MODE)\n");
    // else
    //     printf("WRITE 0x81H FAIL!(IN READ MODE)\n");
    HAL_GPIO_WritePin(GPIOA, GPIO_PIN_4, GPIO_PIN_SET);
    
    *readData = readBuf[1];
    return res;

NOTE:
-只要 XCS 保持低电平，就会被识别为突发传输模式，目标地址会每传输 8 位数据自动递增 1
