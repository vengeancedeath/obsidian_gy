#PID-通用闭环控制算法

#基本情况
例如电机 PID 调节，核心是通过 Kp（比例）、Ki（积分）、Kd（微分）三个参数的组合，让电机转速 / 位置 快速、平稳、无静差 地跟踪目标。

1.比例项 P (Kp)
- 作用：根据 当前误差 直接输出控制量（PWM）
- 效果：
    - Kp 太小 → 响应慢、跟不上目标
    - Kp 太大 → 振荡、抖动、超调大
- 口诀：P 越大越冲，越小越慢

2.积分项 I (Ki)
- 作用：累积 历史误差，彻底消除稳态静差（比如带负载时转速总比目标低一点）
- 效果：
    - Ki 太小 → 静差消不掉
    - Ki 太大 → 超调变大、振荡加剧、积分饱和
- 口诀：I 越大消差越快，但容易冲过头

3.微分项 D (Kd)
- 作用：根据 误差变化速率 提前阻尼，抑制超调、减震
- 效果：
    - Kd 太小 → 抑制不住超调
    - Kd 太大 → 对噪声敏感、电机高频抖
- 口诀：D 是刹车，宜小不宜大

总结
**P** 比例：看**现在**的误差
**I** 积分：看**过去**的累积误差
**D** 微分：看**未来**的误差变化趋势

#工程调参四步法（最实用）

原则：先 P → 再 I → 最后 D

例如电机：

步骤 1：只开 P，找临界稳定
- 设 Ki=0，Kd=0
- 目标值设为 最大转速 60%~70%
- 从小到大慢慢加 Kp：
    - 电机不动 → 加 Kp
    - 刚出现 持续振荡 → 记为 Ku（临界 Kp）
    - 再把 Kp 降到 Ku 的 60%~70% 作为初始值
    
步骤 2：加 I，消除静差
- 保持 Kp 不变
- Ki 从 0 慢慢增大：
    - 直到 稳态误差消失
    - 出现振荡 → 减小 Ki
    - 一般 Ki ≈ Kp 的 1/5~1/20
步骤 3：加 D，抑制超调
- 保持 Kp、Ki 不变
- Kd 从 0 很小开始加：
    - 超调变小、曲线变平滑 → 合适
    - 电机高频抖 → 减小 Kd
    - 一般 Kd ≈ Kp 的 1/10~1/5

#常见问题与解决

| 现象      | 原因            | 解决                |     |
| ------- | ------------- | ----------------- | --- |
| 电机剧烈抖   | Kp 太大 / Kd 太小 | 降 Kp 20%，加 Kd 50% |     |
| 响应慢、跟不上 | Kp 太小 / Ki 太小 | 加 Kp 10%，加 Ki 20% |     |
| 有静差、稳不住 | Ki 太小 / 积分饱和  | 加 Ki，启用积分限幅       |     |
| 超调大、冲过头 | Kp 太大 / Ki 太大 | 降 Kp、降 Ki         |     |
| 高频噪声抖   | Kd 太大 / 反馈噪声  | 减 Kd，加一阶滤波        |     |

 #公式
 
 1.P 比例控制（核心主力）
 ![[Pasted image 20260428162523.png]]
误差越大，出力越大；误差越小，出力越小
 优点：响应快、快速缩小误差
 缺点：只靠 P，永远达不到精准目标，会留一点固定误差（静差）
 
 2.I 积分控制（负责精准）
 ![[Pasted image 20260428163025.png]]
 把每一秒的误差全部累加起来
 优点：消除静差，做到 100% 精准
 缺点：容易积分饱和（误差长期很大，积分堆爆，失控）

3.D 微分控制（负责稳定、刹车）
![[Pasted image 20260428163144.png]]
不看误差大小，只看误差变化有多快
优点：抑制超调、削弱振荡、抑制抖动、增加系统稳定性
缺点：D 太大 → 过度敏感、放大杂波噪声
很多低速场景（温控、水位）甚至可以不用 D

完整位置式公式
![[Pasted image 20260428163420.png]]
![[Pasted image 20260805153659.png]]
输出 = Kp * 误差 + Ki * 积分累加 + Kd * 微分

#参考参数
1.直流电机（带编码器）
- Kp：1~5
- Ki：0.01~0.1
- Kd：0.05~0.5
2.步进电机（闭环）
- Kp：5~20
- Ki：0.1~1
- Kd：0.1~1
3.无刷电（FOC）
- 速度环：Kp=2~8，Ki=0.5~2
- 位置环：Kp=10~50，Ki=1~5
