#Command_Format_命令格式：
0x02 + Addr[23:16] + Addr[15:8] + Addr[7:0] + Parameter...

Addr[23:16] = 0x00
Addr[15:8] = Register Command
Addr[7:0] = 0x00
Addr = 0x00_CMD_00
无参数 无parameter

例如 地址80h,值01h    02 00 80 00 01  /   02 00 11 00

#Image_Format_命令格式：
0x32 + Addr[23:16] + Addr[15:8] + Addr[7:0] + pixels......

2Ch = Memory Write
3Ch = Memory Write Continue

例如  32 00 2C/3C 00 Pixel_Data...

#Power_Sequence

- 上电 AVCI33 → AVCI18 → IOVCC，等待稳定
- 拉低 `RESX` 至少 15μs，再拉高释放复位
- 配置寄存器
- 拉高ELVDD
- 发送0x11 退出休眠
- 等待TE信号 垂直同步
- 发送0x29 开启显示
- 拉高ELVSS
