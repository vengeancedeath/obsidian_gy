空闲任务 - 作用：
1.确保有一个任务在运行
2.负责释放被删除的任务的内容（正常任务删除只是修改一个标志位，需要空闲任务才会释放资源）
3.低功耗

#MPU
MPU 全称 Memory Protection Unit（内存保护单元），是 ARM Cortex-M 系列内核可选的硬件安全模块，相当于给芯片的内存（Flash、SRAM、外设寄存器地址空间）加了一套「硬件门禁」

MPU 相关的高级功能,
3 个硬件基础能力：
- 内存访问权限管控
   可以把内存划分为多个独立区域（不同内核支持 8~16 个区域），给每个区域单独设置权限规则：
	-读写权限：只读、可读写、完全不可访问；
	-特权等级：仅特权级（内核 / 中断可访问）、用户级（普通任务可访问）
- 硬件级栈溢出检测
    可以给每个任务的栈区域末尾，设置一小块「不可访问的保护页」，一旦任务栈溢出、踩到保护页，MPU 会立刻触发异常。
	对比 FreeRTOS 自带的软件栈水位检测（只能事后查询剩余空间），MPU 硬件检测是实时、零延迟的，不会等溢出已经破坏了其他数据才发现问题
- 内存属性配置
	可以给不同内存区域设置缓存、共享、访问顺序等硬件属性：
	比如外设寄存器区域设置为「设备内存、禁止缓存」，避免因 CPU 缓存导致的外设读写异常；
	比如 SRAM 数据区开启缓存提升读写速度，同时配置共享属性保证多总线访问一致性。

NOTE:
内核带有MPU
- Cortex-M3/M4/M7 内核的绝大多数型号（STM32F1/F4/F7、GD32F3/F4 等）；
- Cortex-M23/M33 等带安全扩展的内核（普遍标配 MPU）。

内核没有MPU
- Cortex-M0/M0+ 内核的所有芯片（STM32F0/G0、HC32L110 等）
