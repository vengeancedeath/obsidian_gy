#static
被 static 修饰的东西，属于【类本身】，不属于【类的实例（对象）】

1.
-普通成员：必须 new创建对象之后才能访问
-静态成员：不需要 new 对象，直接通过 类名.成员访问

2.
-静态字段 static 变量 - 所有对象共享同一份数据
![[Pasted image 20260724164454.png]]

3.
-静态构造函数 static Person(){}
只会自动执行一次，第一次使用这个类时触发
不能写参数、不能手动调用、不能加访问修饰符（默认 private）- 常用于初始化静态变量、加载配置

4.
-静态类 static class
不能 new 创建对象
里面所有成员强制要求 static- 典型例子：Console、Math

5.
-静态方法 static 函数
![[Pasted image 20260724165711.png]]


NOTE:
类名和函数名 一样 是构造函数： new 的时候自动执行
所有的字段和方法都在类里面
