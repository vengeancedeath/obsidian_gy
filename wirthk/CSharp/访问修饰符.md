#static
被 static 修饰的东西，属于【类本身】，不属于【类的实例（对象）】

1.
-普通变量/方法：必须 new创建对象之后才能访问
-静态变量/方法：不需要 new 对象，直接通过 类名.成员访问

2.
-静态变量 - 所有对象共享同一份数据
![[Pasted image 20260724164454.png]]

3.
-非静态方法 -可掉用静态/非静态  变量/方法
-静态方法 -可掉用静态变量/方法
静态方法 和非静态方法 在本身的类内部，可以直接调用方法名使用

4.
-静态构造函数 static Person(){}
只会自动执行一次，第一次使用这个类时触发
不能写参数、不能手动调用、不能加访问修饰符（默认 private）- 常用于初始化静态变量、加载配置

5.
-静态类 static class
不能 new 创建对象
里面所有成员强制要求 static- 典型例子：Console、Math


NOTE:

#const和readonly
-const - 只支持基础类型：数值、bool、char、string、null；
	隐式 static，不用写 static；实例无法访问，只能 类名.常量
	只能在声明处直接赋值
-readonly - 基础类型、struct、class、数组都可以
	声明时初始化
	实例构造函数（实例 readonly） / 静态构造函数（static readonly）- 构造执行完毕后，任何地方不能再次修改
