#基本知识
Cortex -A   高性能，运行复杂操作系统  支持MMU（Memory Management Unit，内存管理单元） (TLB)
Cortex -R   可靠性与确定性的快速响应
Cortex -M  低功耗与低成本

4字节 = 1字

IAP 全称 In-Application Programming（应用编程)，不用仿真器的都是IAP烧录/升级
ICP 全称 In-Circuit Programming （连线编程)，用仿真器烧录/升级
ISP 全称 In-System Programming （系统内编程)，通过自带的Bootloader烧录/升级

DFU 全称 Device Firmware Upgrade（设备固件升级），是 USB 官方组织定义的标准 USB 设备类协议，专门用来给 USB 设备升级固件。

STM32三种启动模式：Flash内存启动，系统内存Bootloader启动（烧程序），SRAM内存启动

printf 调用的是fputc函数，重定义fputc函数，就可以调用printf



#RAM变量
栈 (Stack) 和 堆 (Heap) 只是 RAM 里的一小块区域
剩余大部分 RAM：给全局变量、静态变量

栈：
函数内部的 普通局部变量（不加 static）
函数的参数
函数调用的返回地址

堆：
`malloc / calloc / free` 手动申请 / 释放的动态内存

RAM
全局变量（函数外面定义）
静态局部变量（函数内 + `static`）

#args
不能直接把一个函数的可变参数传给另一个可变参数函数 需要用`va_list` 来中转可变参数
    // 格式化日志消息
    va_list args;  // 定义可变参数列表指针
    va_start(args, format); // 初始化 args，从 format 参数之后开始定位可变参数
    int length = format_log_message(logger.log_buffer, sizeof(logger.log_buffer),
                                    level, tag, format, args);
    va_end(args);  // 清理 args，结束可变参数的访问
